Every pixel holds a 128-bit string on a plane with edges (no wrap-around). Each turn runs the four swap phases in the fixed order UD0, LR0, UD1, LR1; the edge column or row that a phase's brick pattern leaves out pairs along the edge instead, with a brick offset that alternates by turn, so every pixel takes part in four exchanges a turn (a corner in three). Then comes a block of bit-plane median filtering passes (entropy decrease), then the local changer: every pixel's 16 bytes are replaced by what the changer makes of them, so the decompressed text or the Brainfuck tape becomes the pixel's new content. With Cells set to Links, every pair of neighbouring pixels has instead two CPUs of its own, one per direction, each of which runs one instruction per phase on the two pixels as its 32-byte memory; a turn makes 128 such rounds of the four phases (the Link rounds box) before the lattice is drawn, and the machines start each turn fresh, PC 0 and registers 0, unless the Link reset box lets them keep their registers for several turns or for good. Last, mutation flips a random share of all bits (0.001 % by default, about 335 bits a turn on a 512 × 512 grid). A swap phase pairs every pixel with one neighbour, left–right (LR) or up–down (UD), at an even (0) or odd (1) offset, so within one turn every pixel exchanges once with each of its four neighbours. For each pair the two strings are compared position by position; where the bits differ, the 32 bits around that position in each pixel are hashed separately and the two 64-bit hashes added, so the decision does not depend on which pixel is which. The first position whose sum falls below the swap threshold is swapped; swaps conserve the total number of set bits. The swap probability is a linear gradient along the x axis from the left-edge value to the right-edge value, each 0 to 1. A median filtering pass works on each of the 128 bit planes separately: it looks at every bit that disagrees with the majority of its neighbourhood (the 3 × 3 block by default, or itself and its four 4-connected neighbours, or the 5 × 5 block), hashes the pixel's 32 bits around that position, and if the hash is below the smoothing threshold the bit takes the majority value. The median filtering probability is a linear gradient along the y axis from the top-edge value to the bottom-edge value. The image is drawn through a render buffer: each pixel's colour is an exponential average of the rendered frames whose half-time is 200 ms or 4 turns, whichever is longer at the current turn rate, and by default a second buffer integrates the output of the first in the same way (two stages in cascade), so flicker is damped and the slower dynamics carry more weight. Where a pixel's whole 3 × 3 neighbourhood in the new frame has exactly its colour (8-connected flat) the half-time is 2 × longer by default (4 × selectable, or the same, or 2 × for 4-connected flat and 4 × for 8-connected flat). The averaged image is then sharpened a little: each channel becomes 2 × the pixel minus the mean of its four 4-connected neighbours, clamped to 0–255 (switchable). Neither step feeds back into the lattice. Each pixel's bits are also read as a stream of copy commands against a static dictionary, the Declaration of Independence, and expanded to exactly 128 bits. The first ⌈log₂ N⌉ bits (13 for this dictionary of N = 8,122 bytes) select a start byte, the "LZ cursor offset" (0 to N) is added, and the cursor wraps at the end of the text. Every command is a prefix-coded copy length of 2 to N bytes followed by a 3-bit skip: the cursor skips that many bytes, the copy is taken from the dictionary at the cursor, and the cursor moves past it. Copies are the only way to make output; there are no literals and no distances, and neither the image nor the output is ever read back. The decompression slider sets N, the longest copy. Optionally two neighbouring cells (columns 2i and 2i + 1) are changed together: their 256 bits are joined, either concatenated (A then B on even turns, B then A on odd turns) or bit-interleaved (A on the even bit positions and B on the odd ones, swapped on odd turns), the changer runs once on the 32-byte joint cell (a CPU then has 32 bytes of memory, the decompressor 256 input bits and 32 output bytes), and the result is split back by the same mapping in reverse. The changers defined on exactly 128 bits (PDP-8, UNIVAC 1101, CDC 6600) see the joint cell as two consecutive 16-byte cells; the DCT becomes a 32-point transform over it. The local changer can instead be a Brainfuck interpreter: the 16 bytes are a program (values 0–7 are the eight commands, anything else a comment) run on a 16-cell tape, and the tape afterwards is the new content; the "Random bytes 0–7" start fills the field with programs. Simpler processors are available too: do nothing, invert, reverse bytes, add 17 (1 to the smallest byte, 17 to the byte after it, 5 to the byte before it), a DCT and its inverse (16-point on a cell, 32-point on a pair). And sixteen machines, a Zilog Z80, MOS 6502, Intel 8080, Subleq, CHIP-8, Intel 4004, Game Boy SM83, Intel 8051, Motorola 6809, RISC-V RV32EC, DEC PDP-8 (8 words of 12 bits), DEC PDP-11 and Motorola 68000: the 16 bytes are the whole memory, the selected number of instructions run, the memory is written back, and halting instructions are NOPs. Threads splits the grid into horizontal bands, one Web Worker with its own wasm instance per band; each band receives a few halo rows from its neighbours once per turn and runs the whole turn locally, bit-identical to the single-threaded run. Scale 1:1 maps one lattice pixel to one device pixel and blits the wasm pixel buffer straight to the canvas. Click a pixel to inspect it; shift-drag paints pixels to all ones, ctrl-shift-drag to all zeros. Keys: space play/pause, n step, r random.
