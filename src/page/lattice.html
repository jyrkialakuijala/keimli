Run

Start chooses the first lattice; Reset starts again from it, Random from random bits. A turn runs the four swap phases, the median passes and the rewriting, then one frame is drawn; Speed sets how many turns a second. Threads splits the grid into horizontal bands, one Web Worker each, bit-identical to a single thread. Click a pixel to inspect it, or hold the button and drag to move the selection; shift-drag paints ones, ctrl-shift-drag zeros. Keys: space play/pause, n step, r random.

Mixing neighbours trade bits · entropy increase through gene swapping

Every pixel is a 128-bit string on a plane with edges. A swap phase pairs each pixel with one neighbour, left–right or up–down at an even or odd offset, so in a turn it exchanges once with each of its four neighbours. Where two strings differ, the 32 bits around that position in each pixel are hashed together, and every position whose hash falls below the threshold is exchanged: a uniform crossover that conserves the set bits. p runs along the x axis from the left-edge to the right-edge value, shaped by the Gradient power; the crossover rate is 2p(1 − p), so 0 and 1 are the identity and 0.5 the strongest mixing. Mixing rule chooses between the four swap phases and a synchronous rule that reads the whole map once and lets every bit where a 4-connected neighbour differs take that neighbour's value by hash, at the same rate, writing only the local pixel, isotropic as in the game of life (bits are then not conserved). Swap order chooses how the four phases are sequenced: fixed UD0 LR0 UD1 LR1 lets lateral mixing act last every turn and correlates the lattice further along y than along x; the default turns the pattern by 90° each turn, which made the two directions equal within measurement and gave the most ordered lattice. Mutation flips a random share of all bits. With "Choosing a new pixel resets the flat twin" ticked, every click also starts the twin again from random bits, while the main lattice goes on. "Flat twin" runs a second lattice under the first, from the same random start, with the selected pixel's values over its whole grid, so the gradient frame and one point of it are seen side by side.

Settling majority vote per bit plane · entropy decrease through median filtering

A pass works on each of the 128 bit planes separately: a bit that disagrees with the majority of its neighbourhood, the 3 × 3 block by default, takes the majority value when the hash of the pixel's 32 surrounding bits falls below the threshold. p runs along the y axis from the top-edge to the bottom-edge value; Passes sets how many passes a turn.

Rewriting a decoder or CPU rewrites every cell · the local changer

Every pixel's 16 bytes are replaced by what the changer makes of them. A Decoder reads them as a coded stream and writes what it decodes back: the LZ decompressor copying from the dictionary, Deflate, LZ4, Snappy, a Brotli-like coder, a prefix code, Morse, Rice residuals, WebP's boolean decoder, PNG filters, a JPEG block or the codebooks. A Transform applies a fixed rule such as invert, reverse, sort, a DCT, an elementary rule on the cell's bits as a ring (four with an exactly known loss of information: none, none, one bit and two bits a turn), or Conway's look-and-say in a base from 2 to 16 (the cell read as one number in that base, each run of equal digits rewritten as its length and the digit). A CPU runs the bytes as its whole memory for the chosen number of instructions and writes the memory back. With Cells set to pairs, two neighbouring cells are joined into one 32-byte cell for the changer and split back afterwards ("rewrite to A cell" and "rewrite to B cell" choose which of the two take the result, A being the leading cell this turn; both off, no changer runs). The "Self and its 4-neighbour vote" entries join every cell with a cell made from its four neighbours instead of with a neighbour: in each bit plane three or four neighbours set give 1, none or one give 0, two leave the cell's own bit, and a neighbour beyond the edge of the grid counts as the cell itself; the vote is taken from the state before any cell is rewritten and only the cell itself is written back, so the step is synchronous and isotropic, as in the game of life; with a CPU or the LZ decompressor, pairs instead carry persistent link machines, one per direction, each running one instruction per phase. The dictionary, the skipped bits, the cursor read range and offset and the longest copy shape the decoders that use them; the inspector below the lattice shows what the selected cell decodes to. With "Random start on change of dictionary" ticked (the default), choosing another dictionary starts again from random bits; unticked, the running lattice keeps its cells and the new dictionary takes over from them.

Display rendering

Each pixel's colour is the average of its 16 bytes' colours through the palette, stretched around the previous frame's mean. Frames pass through a render buffer, an exponential average with a half-time of 200 ms or 4 turns in two stages, so flicker is damped; temporal sharpening adds back what a slower third stage has not yet followed; cycles of 2 to 8 turns show as column phases mixed with the cycle mean; spatial sharpening comes last. None of this feeds back into the lattice. Scale 1:1 maps one pixel to one device pixel.
