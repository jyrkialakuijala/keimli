Every pixel holds a 128-bit string on a plane with edges (no wrap-around). Each turn runs the four swap phases LR0, UD0, LR1, UD1 once each, always alternating left–right and up–down, which leaves 8 orders: turn t uses order t mod 8, so the orders cycle and none of them shapes the long run. The cycle is arranged so that consecutive orders differ as much as possible (every phase moves at least one place, 6 of the 8 steps move the phases the maximum total of 8 places, and no two consecutive turns share a first or a last phase). Then comes a block of bit-plane smoothing passes, and finally the byte changer: every pixel's 16 bytes are replaced by what the changer makes of them, so the decompressed text or the Brainfuck tape becomes the pixel's new content. A swap phase pairs every pixel with one neighbour, left–right (LR) or up–down (UD), at an even (0) or odd (1) offset, so within one turn every pixel exchanges once with each of its four neighbours. For each pair the two strings are compared position by position; where the bits differ, the 32 bits around that position in each pixel are hashed separately and the two 64-bit hashes added, so the decision does not depend on which pixel is which. The first position whose sum falls below the swap threshold is swapped; swaps conserve the total number of set bits. The swap probability is a linear gradient along the x axis from the left-edge value to the right-edge value, each 0 to 1. A bit-plane smoothing pass works on each of the 128 bit planes separately: it looks at every bit that disagrees with the majority of its neighbourhood (itself and its four 4-connected neighbours, the 3 × 3 block, or the 5 × 5 block, selectable), hashes the pixel's 32 bits around that position, and if the hash is below the smoothing threshold the bit takes the majority value. The bit-plane smoothing probability is a linear gradient along the y axis from the top-edge value to the bottom-edge value. The image is drawn through a render buffer: each pixel's colour is an exponential average of the rendered frames whose half-time is 200 ms or 4 turns, whichever is longer at the current turn rate, and by default a second buffer integrates the output of the first in the same way (two stages in cascade), so flicker is damped and the slower dynamics carry more weight. Where a pixel's whole 3 × 3 neighbourhood in the new frame has exactly its colour (8-connected flat) the half-time is 2 × longer by default (4 × selectable, or the same, or 2 × for 4-connected flat and 4 × for 8-connected flat). The averaged image is then sharpened a little: each channel becomes 2 × the pixel minus the mean of its four 4-connected neighbours, clamped to 0–255 (switchable). Neither step feeds back into the lattice. Each pixel's bits are also read as a stream of copy commands against a static dictionary, the Declaration of Independence, and expanded to exactly 128 bits. The first ⌈log₂ N⌉ bits (13 for this dictionary of N = 8,122 bytes) select a start byte, the "LZ cursor offset" (0 to N) is added, and the cursor wraps at the end of the text. Every command is a prefix-coded copy length of 2 to N bytes followed by a 3-bit skip: the cursor skips that many bytes, the copy is taken from the dictionary at the cursor, and the cursor moves past it. Copies are the only way to make output; there are no literals and no distances, and neither the image nor the output is ever read back. The decompression slider sets N, the longest copy. The byte changer can instead be a Brainfuck interpreter: the 16 bytes are a program (values 0–7 are the eight commands, anything else a comment) run on a 16-cell tape, and the tape afterwards is the new content; the "Random bytes 0–7" start fills the field with programs. Simpler processors are available too: do nothing, invert, reverse bytes, add 17 (1 to the smallest byte, 17 to the byte after it, 5 to the byte before it), a 16-point DCT and its inverse. And sixteen machines, a Zilog Z80, MOS 6502, Intel 8080, Subleq, CHIP-8, Intel 4004, Game Boy SM83, Intel 8051, Motorola 6809, RISC-V RV32EC, DEC PDP-8 (8 words of 12 bits), DEC PDP-11 and Motorola 68000: the 16 bytes are the whole memory, the selected number of instructions run, the memory is written back, and halting instructions are NOPs. Threads splits the grid into horizontal bands, one Web Worker with its own wasm instance per band; each band receives a few halo rows from its neighbours once per turn and runs the whole turn locally, bit-identical to the single-threaded run. Scale 1:1 maps one lattice pixel to one device pixel and blits the wasm pixel buffer straight to the canvas. Click a pixel to inspect it; shift-drag paints pixels to all ones, ctrl-shift-drag to all zeros. Keys: space play/pause, n step, r random.
